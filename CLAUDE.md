# CLAUDE.md

Instructions for AI agents in this repository live in **[`AGENTS.md`](AGENTS.md)**. Read it before
doing anything else.

It is kept in one place rather than duplicated here, so the two cannot drift apart.

**The short version, if you read nothing else:**

1. Check `gh issue list` first — GitHub Issues is the task queue, not this conversation
2. Report to the user what is assigned to you and what is blocked on them
3. An unassigned issue is a proposal. Do not start work that was not assigned
4. Open pull requests; do not merge them, and never publish a release
